# Moroccan Secrets

Instructions and guidelines for AI agents working on this project:

- **Stack**: TanStack Start (React 19), Vite 8, Tailwind CSS v4, Nitro (Cloudflare Module preset), Supabase.
- **Routing**: File-based routing located in `src/routes/`.
- **Design System & Branding**: Warm heritage aesthetic inspired by Moroccan riads:
  - Primary burgundy: `#8B1A1A`
  - Accent deep green: `#2F5D34`
  - Gold: `#C9A24B`
  - Warm cream background: `#FDFCF9`
  - Ink foreground: `#2A2A2A` / `#1C1817`
- **Testing**: Vitest (`npm test`). Keep all tests passing.
